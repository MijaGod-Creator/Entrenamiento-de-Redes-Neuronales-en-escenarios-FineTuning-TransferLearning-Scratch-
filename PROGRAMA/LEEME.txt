=====================================================================
  SISTEMA DE RECONOCIMIENTO DE EMOCIONES FACIALES (FER)
=====================================================================

Este directorio contiene los accesos directos para la instalación e
iniciación de las interfaces interactivas (Web y Escritorio) en Windows.

---------------------------------------------------------------------
REQUISITOS PREVIOS:
---------------------------------------------------------------------
- Tener instalado Python 3.10 o Python 3.11 en Windows.
- Si no está instalado, descárgalo de la tienda de Microsoft (Microsoft Store)
  buscando "Python 3.11", o desde la web oficial: https://www.python.org/downloads/
  * IMPORTANTE: Durante la instalación, marca la casilla "Add Python to PATH".

---------------------------------------------------------------------
INSTRUCCIONES DE USO:
---------------------------------------------------------------------

Paso 1: Instalación (Solo se hace la primera vez)
   - Haz doble clic sobre el archivo "Instalar_Programa.bat".
   - Esto creará un entorno virtual limpio de Python, configurará el 
     paquete compatible de stringzilla y descargará todas las librerías 
     necesarias del proyecto automáticamente.
   - Espera a que la consola muestre el mensaje verde de éxito y presiona 
     cualquier tecla para cerrar.

Paso 2: Iniciar la Aplicación (Elige 1 de las 2 opciones disponibles)

   OPCIÓN A: Aplicación de Escritorio Nativa (Recomendada)
      - Haz doble clic sobre el archivo "Iniciar_Escritorio.bat".
      - Esto abrirá una ventana de programa independiente (GUI) sin usar el navegador.
      - Podrás seleccionar dinámicamente qué modelo usar de tu lista de modelos 
        entrenados ( saved_models/ ), usar tu cámara web en tiempo real con 
        detección multirrostro o subir fotos para graficar las métricas.

   OPCIÓN B: Interfaz Web Local (Flask)
      - Haz doble clic sobre el archivo "Iniciar_Programa.bat".
      - Esto levantará un servidor local en segundo plano y abrirá tu navegador 
        predeterminado en: http://localhost:5000 para interactuar con la web.

Paso 3: Cerrar la Aplicación
   - Simplemente cierra la ventana del programa (Opción A) o presiona cualquier 
     tecla en la consola del lanzador para apagar el servidor (Opción B).
